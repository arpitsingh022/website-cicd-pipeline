
# Website CI/CD Pipeline

A professional, responsive portfolio website built using HTML5, CSS3 and JavaScript, with automated deployment planned through GitHub Actions.

## Project Overview

This project demonstrates a modern website development and CI/CD deployment workflow.

The goal is to build a responsive website, manage source code with Git and GitHub, and automate deployment using GitHub Actions.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Actions
- GitHub Pages (planned hosting platform)

## Project Structure

```text
website-cicd-pipeline/
│
├── assets/
├── css/
│   └── style.css
├── js/
│   └── script.js
├── index.html
└── README.md
```

## Features

- Responsive website design
- Modern dark user interface
- About and technical skills sections
- Featured projects section
- Contact section
- Mobile navigation
- Automated copyright year
- GitHub Actions deployment planned

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/arpitsingh022/website-cicd-pipeline.git
   ```

2. Open the project folder:

   ```bash
   cd website-cicd-pipeline
   ```

3. Open `index.html` in your browser.

   Alternatively, use the VS Code Live Server extension.

## Deployment

GitHub Actions will be configured to automate website deployment to GitHub Pages.
